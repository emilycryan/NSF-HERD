# Q10 — Other federal agency sources (entry-list)

**Date:** 2026-06-03
**Status:** Built and verified in the local preview
**Scope:** `data/survey.json` (Q10 content), `js/app.js` (new `entry-list`
renderer), `css/components.css` (entry-list styles).

## Purpose

Populate Q10's drawer to match the paper instrument. Q10 is a **write-in list**:
the respondent names up to 10 funding agencies and enters an amount for each,
which the prototype's existing matrices (fixed row labels) can't express — so it
introduces one new block, `entry-list`.

Paper structure:

- **Question 10.** "Of the amount reported for Other federal sources in Question
  9 (row K, column g), which agencies funded this R&D, and how much …?"
- A skip instruction: "If your institution reported $0 in Question 9, row K,
  column g, skip this question and go to Question 11." (static text — the $0
  condition isn't wired since Q9 isn't built.)
- Four instruction bullets. The 4th references a link to a list of federal
  departments/agencies; rendered as **plain text for now** (no agency-list
  content yet) — see follow-up.
- The list: left header "Federal agencies (list up to 10)", right header
  "R&D expenditures (Dollars in thousands)"; rows a–j (write-in name + amount),
  row k (fixed label + amount), row l (Total, auto-summed a–k).

## New `entry-list` block

`{ lead?, caption?, captionSub?, rows: [...] }` on a 3-column grid
(`auto minmax(0,1fr) 180px`): letter prefix, name/label, amount. `lead` spans
the first two columns; the caption sits over the amount column.

Each row:
- `{ prefix, nameId, amountId }` → letter + **write-in text input** + amount.
- `{ prefix, label, description?, footnoteRef?, amountId }` → letter + static
  label (+ optional description) + amount (e.g. row k).
- add `total: true, sumOf: [...]` for the totals row (row l). Amount cells reuse
  `renderCurrencyInput`, so the total is driven by the existing
  `recomputeTotals()` — no new totaling code.

Name fields reuse the standard `renderInput` (`.form-input`).

## Verification (local preview, port 8766, 1280px)

- Q10 renders intro → skip paragraph → 4 bullets → entry-list (12 rows) →
  footnote → comments → action-bar.
- Name fields are text inputs; row k shows its fixed label; the Total row is
  readonly and auto-sums (120 + 60 + 15 → 195).
